## About me

I'm a software developer who learns by shipping. Most of what's on this profile started as a
hackathon weekend or a university brief and ended up as something you can actually clone and run —
a supermarket management system on .NET 8, a fight-prediction simulator in React, and a
zero-dependency 3D solar system that runs entirely in the browser.

- 🧠 Interested in **explainable systems** — deterministic models you can audit, not black boxes.
- 🛠️ I like writing the fundamentals myself: hash tables, binary search trees, sort and search
  algorithms, orbital mechanics. It's the fastest way to actually understand them.
- 🌐 Comfortable across the stack: ASP.NET Core APIs and EF Core on one side, React and browser APIs
  on the other.

## 🚀 Featured projects

### 🛒 [Supermarket Management System](https://github.com/thvb1133/SuperMarket30_UniExam) &nbsp;`C#` `.NET 8` `EF Core` `SQL Server`

A system that takes a small shop from paper records to digital: products, stock control, suppliers,
sales tracking, reporting and low-stock alerts. Built on **hand-written data structures** — a custom
hash table, binary search tree and dynamic array — plus my own search and sort implementations,
persisted through EF Core to SQL Server and exposed as an ASP.NET Core Web API with Swagger and a
built-in dashboard.

▶️ [Video walkthrough of the running system](https://www.loom.com/share/17a071ca6dfa4c0faadfd19b2ce9079d)

### 🤖 [PitBoss — AI Agent Battle](https://github.com/thvb1133/PitBoss_AI_Agent_Battle_Hackathon) &nbsp;`TypeScript` `React 19` `Vite`

An evidence-backed BattleBots matchup simulator covering all 24 robots in the 2026 Pro League. Pick
two robots to get an **explainable win probability**, then redesign the underdog's armor,
reliability, mobility and weapon bite and watch the odds move in real time. Deliberately uses a
deterministic, auditable scoring model rather than an uncheckable LLM opinion, backed by a scraping
pipeline for refreshing robot profiles and fight results. Deploys to GitHub Pages via Actions.

### 🌌 [Beyond Orbit — A Tale of Two Souls](https://github.com/thvb1133/AWShackathon) &nbsp;`JavaScript` `WebGL` `Web Speech API` `PWA`

A cosmic classroom wrapped around a real space app: a 3D solar system driven by orbital mechanics,
live satellite tracking, public NASA and NOAA data, an encyclopedia of discoveries beyond Earth, and
500+ specialist agents you can talk to by voice. **No build step, no framework, no server, no API
key** — just ES modules, an import map and a service worker on a static host.
